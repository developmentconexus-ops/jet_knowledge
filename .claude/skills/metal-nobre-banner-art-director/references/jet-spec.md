# JET Banner Specification

## Current Working Target

Use the actual JET upload requirement supplied by the user as the authority.

Observed JET recommendation:
- width: 1920 px
- recommended height: 500 px
- maximum upload size: 1 MB

Metal Nobre may intentionally use a shallower banner for better above-the-fold efficiency.

Do not invent the final height inside this skill. Before planning a production banner, confirm the current chosen target height for that round.

## File Size

Final upload must stay within the 1 MB platform limit.

Prefer:
- high-quality JPG for photographic banners;
- WebP when accepted and operationally convenient;
- optimized PNG only when transparency or specific rendering needs justify it.

The image-generation session does not need to solve file compression. Compression is a deterministic post-production step.
